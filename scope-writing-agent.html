02 What it does

A second pair of eyes with a long memory.

  1. ComparesYour draft is checked against past scopes for the same trade and project type, so the comparison is like for like.
  2. Surfaces gapsLikely-missing items come with how often they appeared, so a gap is evidence, not a hunch.
  3. Challenges wordingAmbiguous phrases are flagged and turned into clarifying questions to resolve before tender issue.
  4. Confirms and exportsNothing goes in the output until you confirm it. The result is a clean Word list ready for the tender pack.
  5. Says when it doesn’t knowWith fewer than three comparable scopes it tells you so and marks the result low confidence.

04 How it’s built

All the intelligence lives in the library, so it gets better with every scope issued.

  • ServiceA Node.js and Express service backed by Postgres, deployed to Railway, with two parts sharing one database: an admin ingestion tool and the author-facing agent.
  • Reading filesText is extracted from Word, PDF and Excel files, and duplicates are caught by a content fingerprint so the same scope isn’t counted twice.
  • Gap analysisThe AI compares the draft with a frequency map built from the library for that trade and type, then returns structured findings the interface can render.
  • Sessions and exportReviews are saved so you can come back (for seven days), and the confirmed scope is generated as a Word file in code.
  • Human in the loopNothing enters the library without a person confirming it. Authors can also flag a gap the agent missed.
