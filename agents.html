02 Design advice agent

Requirements, referenced.

Ask a design-requirement question for a project and get an answer that names the Act, regulation or code it relies on, and says which sources it checked live and which you should verify.

  • Access to and within the tenancy NCC 2022 Vol. 1 Verify

  • Suggestion Confirm the accessible path with your certifier before the permit set is issued
Illustrative conversation. Checks facts against the sources and flags what to verify. Doesn’t know site permits or council conditions.
