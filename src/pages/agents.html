04 How it’s built

Narrow agents with a shared toolbox underneath.

  • Shared AI layerEvery agent calls one shared wrapper over free-tier models from several providers, with failover and a cooldown for any provider that is struggling.
  • Incident builderA conversation collects the details, then Word templates are filled with docxtemplater and the completed forms are zipped for download.
  • Design adviceVictorian legislation is fetched live from the official source. The national code and standards come from model knowledge and are tagged “verify”.
  • InterfaceThe same React front end and sign-in as the rest of the hub, with per-tool access control.
  • GuardrailsEach agent has a defined job and cites what it relied on. People submit and approve; the agents only prepare.
