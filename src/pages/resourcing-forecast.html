02 What it does

Three views, one set of data.

  1. TimelineA project-by-project grid, coloured by role. Drag to allocate someone, drag an edge to resize, and filter by project, person, role or stage.
  2. CapacityA role-by-month heatmap of how committed people are. Click a cell to see exactly which allocations make up the figure.
  3. GapsA soonest-first list of weeks where a project has nobody covering a single-holder role. An empty list is good news.
  4. Roles and scopeAdmins and planners edit. Viewers read, and can be limited to particular projects. Finished projects are tucked away by default.

04 How it’s built

A planning tool people actually enjoy using, instead of a spreadsheet they dread.

  • ServiceA Node.js and Express service with its own database, deployed to Railway.
  • InterfaceA React front end on the shared component library, with drag-to-create and drag-to-resize built on the timeline itself.
  • Checks as you workConflict detection runs while you drag, and a bar turns red the moment it would overlap another allocation for the same person.
  • AccessRestricted to named people while it is built out, with Admin, Planner and Viewer roles, and viewers can be scoped to specific projects.
  • Honest limitsData starts from when it was entered here. There is no historical import from the old spreadsheet.
