# Gilad Goldman portfolio site

Live at https://gld.gldmn.net. A static site (no framework, no runtime dependencies) built with one Python script and hosted on GitHub Pages. It is a proof of concept: every page shows a "Proof of concept" banner.

## How it fits together

| Piece | Where | Notes |
| --- | --- | --- |
| Site source | this repo (`src/pages/*.html`, `css/`, `js/`, `fonts/`, `build.py`) | Edit `src/pages`, not the generated root `.html` files. |
| Photos | private repo `giladgoldman/portfolio-assets` (`img/*.jpg`, plus `img/*.webp` responsive variants) | Fetched at deploy time with the `ASSETS_TOKEN` Actions secret. Not stored here. |
| CV request form | private repo `giladgoldman/cv-mailer` (a Cloudflare Worker) | Emails the Tech or Construction CV via Resend. See that repo's README. |
| Contact form | Web3Forms (public access key in `build.py`, hCaptcha enabled in the Web3Forms dashboard) | Emails messages to the owner. The owner's address is never on the page. |
| Hosting and domain | GitHub Pages; `CNAME` = `gld.gldmn.net`; DNS is a `gld` CNAME to `giladgoldman.github.io` at Squarespace Domains | HTTPS enforced in Settings -> Pages. |

## Deploying
Push or merge to `main`. `.github/workflows/pages.yml` fetches the photos, runs `python3 build.py`, assembles `_site/` (pages, `css`, `js`, `fonts`, `img`, `robots.txt`, `sitemap.xml`, `llms.txt`, `CNAME`) and deploys it. Work on a branch and open a pull request; branches are best set to delete automatically on merge (Settings -> General).

## Run it locally
```
python3 build.py                       # regenerate the root .html files from src/pages
python3 -m http.server 8000            # preview at http://localhost:8000
```
Photos are not in this repo, so copy `img/*.jpg` and `img/*.webp` from `portfolio-assets` into `img/` to see them locally (they are git-ignored here).

## Configuration (top of `build.py`)
- `form_endpoint` / `form_access_key`: Web3Forms endpoint and public key for the message form.
- `cv_endpoint` / `turnstile_site_key`: the cv-mailer Worker URL and the public Cloudflare Turnstile site key for the "Hire me" CV form.
- `url`: the canonical site URL used for link-preview tags.
- `ga_id`: the Google Analytics 4 measurement ID (`G-...`). The gtag snippet is added to every page; set it to an empty string to turn tracking off.
- Secrets never live in this repo. The only repo secret is `ASSETS_TOKEN` (a fine-grained token with read access to `portfolio-assets`; it expires, so rotate it before the expiry date).

## Folder
- `src/pages/` page sources; `*.html` in the root are generated by `build.py` (including `404.html`)
- `css/style.css` all styles (Oxblood palette, tokens at the top); `js/main.js` clock, reveal animation, contact and CV forms
- `fonts/` self-hosted woff2 (Archivo, JetBrains Mono); `img/favicon.svg` (brick-wall G)
- `design/apply-oxblood.py` the one-off script that applied the current palette (kept for reference)
